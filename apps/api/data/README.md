# Нийтэд байршуулсан асуултын сан

public-question-bank.json нь unit111_admin_test өгөгдлийн сангаас 2026-11-16-нд экспортолсон, нийтлэгдсэн төлөвтэй 763 асуултын snapshot юм. Асуултын текст, сонголт, зөв хариултын тэмдэглэгээ, тайлбар, ангилал болон эх сурвалжийн лавлагаа хадгалагдана.

Энэ файлд хэрэглэгчийн бүртгэл, нэвтрэх мэдээлэл, reviewer-ийн ID, оролдлого, оноо, ахиц, XP, аудитын бүртгэл болон database-ийн холболтын нууц утга ороогүй. Export хийхдээ локал абсолют файлын замыг хассан.

Энэ JSON нь repository-д зориулсан snapshot бөгөөд db:seed-ээр автоматаар database-д орохгүй. GitHub-д байршуулсан нь ажиллаж буй database-ийг өөрчлөхгүй.

question-bank-import/ дотор одоогийн админ importer-т тааруулсан дөрвөн CSV багц байна: 200, 200, 200, 163 мөр. categories.txt нь ангилал тус бүрийн тоог харуулна. Админ ангиллуудыг шалгасны дараа файлуудыг нэг нэгээр нь preview хийж импортлоно. Импортын шинэ бичлэгүүд Draft төлөвтэй, шинэ UUID-тай үүснэ; хичээл/сорилын холбоос болон оролдлогын түүх ороогүй.

78 General асуултад эх баримт болон хуудас/байршлын лавлагаа байхгүй. Эдгээр талбарыг зориуд хоосон үлдээсэн; эх сурвалжийг баталгаажуулж бөглөх хүртэл reviewer нийтлэх боломжгүй. Асуултын техникийн агуулгыг энэ export баталгаажуулсан гэсэн үг биш.

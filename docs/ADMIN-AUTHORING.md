# Admin нэмэх/засах урсгал — 2026-10-20

## Шинэ үндсэн урсгал

- Асуулт: асуулт, A–D сонголт, зөв хариулт → Хадгалах. Тайлбар сонголттой. Шинэ admin асуулт шууд published төлөвөөр үүсэж хичээлд ашиглахад бэлэн болно.
- Source нэр, хувилбар, бүлэг, хуудасны талбарууд шинэ болон засах формоос хасагдсан. Хуучин мэдээллийг database-ээс устгаагүй.
- Асуулт нэмэх, засах нэг ижил формтой; урьдчилан харах хэрэгтэй үед нээгдэнэ.
- Ангилал, хүндрэл, төрөл нь Нэмэлт тохиргоонд эвхэгдэнэ. Ангилал сонгоогүй бол сервер анхдагч идэвхтэй ангилал сонгоно.
- Төстэй асуулт normal нэмэх урсгалын хадгалалтыг хориглохгүй; хадгалсны дараа анхааруулна.
- Хичээл: нэр → Хичээл нэмэх. Асуулт, материалгүй ноорог үүсгээд дараа нь нөхөж болно. Ангилал, дараалал, тайлбар, материал нэмэлт тохиргоонд байна.
- Асуултын сан удирдлагын анхны tab болсон. Excel/CSV импорт эвхэгддэг хэсэгт орсон.
- Асуултын review tab болон хяналтад илгээх үндсэн товч хасагдсан.
- Засварлах боломжтой published асуулт засварын дараа published хэвээр байна. Албан сорилын оролдлогын түүхтэй асуултыг хамгаалдаг дүрэм хадгалагдсан.
- Excel/CSV импортод source болон тайлбар заавал биш. Бөөн импортын файл давхар оруулах хамгаалалт, мөрийн нийцлийн шалгалт хэвээр.
- Онолын блок source/хуудасгүйгээр submit/review хийх боломжтой; source input-ууд editor-оос хасагдсан. Агуулгын бусад role/status урсгалыг энэ ажлаар бүхэлд нь солихгүй.
